## ⚠️ PROBLEMAS DE ÚLTIMA HORA?

### Link do vídeo não funciona:
1. Abra YouTube Studio
2. Vídeos → Seu vídeo → Editar
3. Visibilidade → "Não listado"
4. Salvar → Copiar novo link

### Repositório dá 404:
1. GitHub → Repositório → Settings
2. Danger Zone → Change visibility
3. Make public → Confirmar

### Sistema não inicia:
```bash
rm -rf node_modules
npm install
npm run seed
npm start
```

### PDF muito grande:
1. Acesse: smallpdf.com/compress-pdf
2. Upload seu PDF
3. Baixe versão comprimida
