## 🎥 Dicas de Gravação

### Preparação

1. **Ambiente**
   - Grave em ambiente silencioso
   - Boa iluminação
   - Conexão estável com internet

2. **Software**
   - OBS Studio (gratuito e profissional)
   - QuickTime (Mac)
   - Windows Game Bar (Windows)
   - Loom (online, fácil de usar)

3. **Áudio**
   - Use um microfone decente (headset serve)
   - Teste o áudio antes de gravar
   - Fale de forma clara e pausada

4. **Tela**
   - Feche abas desnecessárias
   - Desative notificações
   - Use resolução Full HD (1920x1080)
   - Zoom adequado para textos ficarem legíveis

### Durante a Gravação

1. **Ritmo**
   - Não fale muito rápido
   - Faça pausas entre seções
   - Dê tempo para o espectador processar informações visuais

2. **Navegação**
   - Movimentos suaves do mouse
   - Evite cliques muito rápidos
   - Destaque elementos importantes

3. **Demonstração**
   - Dados de exemplo devem ser profissionais
   - Evite erros de digitação (prepare textos antes)
   - Tenha um "plano B" se algo não funcionar

4. **Naturalidade**
   - Não precisa ser perfeito na primeira tentativa
   - Pequenas hesitações são normais
   - Pode gravar em partes e juntar depois

### Edição

1. **Cortes**
   - Remova silêncios longos
   - Corte erros e reinícios
   - Mantenha transições suaves

2. **Elementos Visuais**
   - Adicione legendas com nome das seções
   - Zoom em elementos importantes
   - Setas ou círculos para destacar

3. **Áudio**
   - Normalize o volume
   - Remova ruídos de fundo (se possível)
   - Adicione música de fundo suave (opcional)

4. **Intro/Outro**
   - Slide de introdução com título
   - Slide final com contato
   - Créditos se usar música/recursos de terceiros

### Ferramentas de Edição

- **Gratuitas**: DaVinci Resolve, Shotcut, OpenShot
- **Pagas**: Adobe Premiere, Final Cut Pro, Camtasia
- **Online**: Kapwing, Clipchamp
