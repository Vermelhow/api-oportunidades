# 13/06 — Produção do Vídeo de Apresentação

## 📋 Objetivo
Criar roteiro completo e profissional para vídeo de apresentação do projeto, facilitando a produção de um vídeo demonstrativo de 5 a 8 minutos.

## 🎬 Roteiro Criado

### Estrutura Completa

Criado roteiro detalhado dividido em **13 seções** principais:

1. **Introdução (30s)**
   - Apresentação pessoal
   - Nome do projeto
   - Contexto acadêmico

2. **Objetivo Social (30s)**
   - Propósito do sistema
   - Impacto social
   - Público-alvo

3. **Home Page (30s)**
   - Interface inicial
   - Navegação principal
   - Design responsivo

4. **Login (30s)**
   - Processo de autenticação
   - Segurança JWT
   - Redirecionamento

5. **Listagem de Oportunidades (45s)**
   - Visualização de cards
   - Sistema de busca
   - Filtros por categoria/organização

6. **Detalhes da Oportunidade (30s)**
   - Informações completas
   - Dados da organização
   - Candidatura

7. **Dashboard Administrativo (45s)**
   - Visão geral
   - Estatísticas
   - Acesso às funcionalidades

8. **Cadastro de Oportunidades (1min)**
   - Formulário completo
   - Validações
   - Feedback de sucesso

9. **Edição de Oportunidades (45s)**
   - Carregamento de dados
   - Modificação de campos
   - Atualização

10. **Exclusão de Oportunidades (30s)**
    - Modal de confirmação
    - Segurança contra exclusões acidentais
    - Feedback visual

11. **Responsividade (45s)**
    - Desktop, tablet e mobile
    - Menu adaptativo
    - Reorganização de elementos

12. **Tecnologias Utilizadas (45s)**
    - React, Vite, React Router
    - Node.js, Express, SQLite
    - JWT, boas práticas

13. **Encerramento (30s)**
    - Resumo do impacto social
    - Informações de contato
    - Agradecimentos

### Tempo Total Estimado
**~7 minutos** (distribuídos estrategicamente entre as seções)

## 📝 Detalhamento do Roteiro

### Para Cada Seção Incluído:

1. **Tempo estimado** - Duração recomendada
2. **Indicação de tela** - O que mostrar visualmente
3. **Narração completa** - Texto sugerido para falar
4. **Ações na tela** - Passo a passo do que fazer
5. **Transições** - Como passar para próxima seção

### Exemplo de Seção Detalhada:

```
### 8. Cadastro de Oportunidades (1 minuto)

[TELA: Ir para cadastro de oportunidade]

Narração:
"Vamos criar uma nova oportunidade. O formulário de 
cadastro é completo, mas mantém a simplicidade de uso."

Ações na tela:
- Clicar em "Nova Oportunidade"
- Preencher título (ex: "Desenvolvedor Front-end Jr.")
- Preencher descrição
- Selecionar categoria
- Selecionar organização
- Clicar em "Salvar"
- Mostrar mensagem de sucesso
```

## 🎥 Materiais Complementares Criados

### 1. Dicas de Gravação

**Preparação:**
- Ambiente silencioso e bem iluminado
- Software recomendados (OBS, QuickTime, Loom)
- Configuração de áudio
- Resolução de tela adequada

**Durante a Gravação:**
- Ritmo de fala pausado
- Movimentos suaves do mouse
- Dados de exemplo profissionais
- Naturalidade na apresentação

**Edição:**
- Cortes de silêncios longos
- Adição de legendas e destaques
- Normalização de áudio
- Slides de intro/outro

### 2. Ferramentas Sugeridas

**Gravação:**
- Gratuito: OBS Studio, QuickTime, Windows Game Bar
- Online: Loom, Screencastify
- Profissional: Camtasia

**Edição:**
- Gratuito: DaVinci Resolve, Shotcut, OpenShot
- Pago: Adobe Premiere, Final Cut Pro, Camtasia
- Online: Kapwing, Clipchamp

### 3. Checklist Pré-Gravação

**Preparação Técnica:**
- [ ] Sistema rodando sem erros
- [ ] Backend funcionando
- [ ] Dados de exemplo carregados
- [ ] Usuário de teste criado
- [ ] Navegador atualizado

**Preparação Visual:**
- [ ] Resolução 1920x1080
- [ ] Zoom 100%
- [ ] Tema definido
- [ ] Abas organizadas
- [ ] Notificações desativadas

**Preparação de Conteúdo:**
- [ ] Textos preparados
- [ ] Fluxo testado
- [ ] Timing checado
- [ ] Dados profissionais

**Preparação de Áudio:**
- [ ] Microfone testado
- [ ] Volume adequado
- [ ] Roteiro acessível
- [ ] Ambiente silencioso

## 📝 Exemplo de Uso

### Como Seguir o Roteiro:

1. **Preparação** (1 dia antes)
   - Ler roteiro completo
   - Fazer checklist pré-gravação
   - Testar fluxo no sistema
   - Preparar dados de exemplo

2. **Gravação** (dia da produção)
   - Configurar ambiente
   - Seguir narração sugerida
   - Executar ações indicadas
   - Gravar em partes se necessário

3. **Edição** (após gravação)
   - Juntar partes gravadas
   - Remover erros e pausas longas
   - Adicionar elementos visuais
   - Normalizar áudio

4. **Revisão** (antes de publicar)
   - Assistir vídeo completo
   - Verificar qualidade de áudio
   - Checar legibilidade do texto
   - Confirmar duração adequada
